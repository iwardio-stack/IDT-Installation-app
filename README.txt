IDT INSTALLATION SIGN-OFF PHONE APP

Features:
- Client and installer details
- Client and installer finger signatures
- Site photo uploads
- Notes and outstanding items
- Acceptance block
- Save/load on the phone
- Create PDF report using Android/Chrome Print > Save as PDF
- Share the saved PDF using Android Share to WhatsApp or Email

Use:
1. Extract the ZIP.
2. Open index.html in Chrome.
3. Add it to the Home screen.
4. Complete the form.
5. Tap Create PDF Report.
6. Select Save as PDF.
7. Open the saved PDF and tap Share, then choose WhatsApp or Email.

Note: This is a mobile web app, not a compiled APK.
